# Hyunjin Archive

현진의 활동과 순간을 기록하는 정적 아카이브 사이트입니다. 레퍼런스의 미니멀한 편집 디자인을 바탕으로 만들었으며, 첫 화면에는 아카이브 인덱스만 표시합니다.

## 시작하기

별도 설치나 빌드 과정 없이 `index.html`을 브라우저에서 열면 확인할 수 있습니다. 온라인에 공개하려면 GitHub Pages, Netlify, Vercel 같은 정적 호스팅 서비스에 프로젝트 폴더를 업로드하면 됩니다.

## 구성

- `index.html`: 아카이브 첫 화면
- `styles.css`: 반응형 레이아웃
